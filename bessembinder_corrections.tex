\maketitle

\noindent
Daily Compustat prices/returns matched to CRSP on \texttt{(permno, date)}
(inner join). \textsc{raw} uses the uncorrected Compustat panel;
\textsc{bessembinder} applies the Section~6 decimal-error corrections and
Section~8 outlier filters. $\Delta$ $=$ \texttt{ret\_comp} $-$
\texttt{ret\_crsp}. Size groups use Compustat NYSE (\texttt{exchg=11}) monthly
breakpoints (1/20/50/80 percentiles of month-end market equity).

\medskip
\noindent
\textbf{All possible matches: Compustat is not filtered.} Only the CRSP ground
truth is screened to common stock on a main exchange via the V2 (CIZ) fields
(\texttt{securitytype=EQTY}, \texttt{securitysubtype=COM}, \texttt{sharetype=NS},
\texttt{issuertype}$\in\{$ACOR,CORP$\}$, \texttt{primaryexch}$\in\{$A,N,Q$\}$,
\texttt{conditionaltype=RW}). Returns are gap-guarded: when Section~8 removes an
observation, the next surviving day's return is nulled rather than spanning the
gap.

\medskip
\noindent
\textbf{Missing-\texttt{trfd} returns recovered.} Compustat's daily total-return
factor \texttt{trfd} is missing for securities that never pay a dividend
($\sim$45\% of US securities; \texttt{ri} and hence the return were previously
null for them). Per Compustat guidance we set \texttt{trfd}$=1$ for
never-dividend securities only (no dividends $\Rightarrow$ price return $=$ total
return), recovering $\sim$18M returns.

\medskip
\noindent
\textbf{Extreme Compustat returns dropped.} Returns with
$|\texttt{ret\_comp}|>10$ are dropped from both panels. The raw \texttt{ri}
carries negative Compustat quote-prices (bid/ask) and residual decimal errors
that produce a handful of impossible returns (e.g.\ \texttt{ret\_comp} of
$+259$, $+177$, $+161$). A few hundred such rows are variance-dominant and
single-handedly collapse the Pearson correlation; dropping
$|\texttt{ret\_comp}|>10$ removes them and restores the all-stocks correlation
from $0.821$ to $0.976$ (Bessembinder) and from $0.034$ to $0.953$ (raw). This
is a coarse stand-in for JKP's downstream winsorization of Compustat returns
against CRSP, which is not applied here.
